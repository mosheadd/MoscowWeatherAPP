# Moscow Weather App
## Installment
1. Clone the repo
    ```
    git clone https://github.com/mosheadd/MoscowWeatherAPP.git
    ```
2. Install needed libraries:
    ```
    pip install -r requirements.txt
    ```
3. Run the version using already made predictions:
    ```
    streamlit run app_no_pred.py
    ```
4. Run the version with training and making predictions locally (***Python Version 3.12 needed***):
    ```
    python run.py
    ```
   If you dont have python of 3.12 version installed, install it and run this command:
    ```
    py -3.12 run.py
    ```
